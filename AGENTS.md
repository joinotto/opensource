# Project instructions

Keep this project independent of unrelated repositories and private data.
Do not commit credentials. Store implementation-only notes and evidence under
ignored `.opensource/`. Keep public documentation under `docs/`.

Run `npm test` after code changes. Test generated projects and installed skills,
not just template wording. Use truthful status and actual author signoffs.
Do not publish, create external repositories, push, or change account settings
without explicit authorization.

Use short operational instructions where ambiguity matters. STE is a writing aid,
not a forced vocabulary or a compliance claim.
