# Contributing

Keep changes small and add behavior tests. Run `npm run check`. Test skills,
TypeScript single/workspace packages, and common-only output. Include filesystem
preservation and negative release-policy cases when relevant.

Put private implementation notes and temporary helpers under ignored `.opensource/`.
Public tests, templates, and maintained tooling are part of the core project.
Do not commit secrets or unrelated project content.

Use your real author identity. Sign off contributions with `git commit -s` only
when you can make the Developer Certificate of Origin certification.
See https://developercertificate.org/. Generated code remains the contributor's responsibility.
